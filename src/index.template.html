動画を作り直しますか？

今の完成動画は削除され、新しい設定や並び順で作り直します。まだ保存していない場合は、先にMP4を保存してください。

使い方と注意事項

写真や動画をまとめて選び、1素材1秒でつないだ動画を作るツールです。必要ならBGMと撮影年の区切りを追加できます。複雑な動画編集機能はありません。

1素材 = 1秒画像は1秒表示し、動画は選んだ1秒を使います。
BGMは任意素材動画の元音声は使わず、必要ならBGMを1曲ループできます。

使い方

  1. JPEG / PNG / WebP画像、MP4 / WebM動画をまとめて選びます。
  2. 並び順と自動で選ばれた1秒を確認します。「並べ替え」から「全素材を逆順にする」で写真も含む全体を反転できます。動画を選ぶと使う1秒を調整できます。削除の「元に戻す」は5秒間で、読み込み・作成中は操作できません。
  3. 「動画を作る」を押し、完成後にプレビューしてMP4を保存します。

対応ファイル

画像はJPEG / PNG / WebP、動画はMP4 / WebMに対応します。MOV / M4Vはブラウザーで再生できる場合のみ読み込めます。

仕上がり

1素材1秒は固定です。動画の形や表示方法に加え、BGMと撮影年の区切りも必要なときだけ追加できます。

プライバシー

選択した写真・動画・音楽はブラウザー内だけで処理し、外部サーバーへ送信しません。生成した動画も自動送信せず、「MP4を保存」を押したときだけ端末へ書き出します。

このアプリから利用状況やファイル情報を外部へ送信する仕組みも入れていません。

キーボード操作

  • Tab / Shift+Tabで操作項目を移動できます。ダイアログ内をスクロールしても背景のページは動きません。並べ替え・削除・元に戻す操作後も、対応する操作項目へフォーカスが戻ります。
  • Enter / Spaceでボタンや動画カードを操作できます。
  • 動画の1秒位置は矢印キーでも変更できます。
  • ダイアログはEscapeで閉じられます。

注意事項

  • MP4を作れないブラウザーでは利用できません。その場合は最新のChromeまたはEdgeでお試しください。
  • 動画作成には完成動画と同程度の時間がかかります。途中でキャンセルしても読み込んだ素材は残ります。
  • 大量素材の処理上限は端末の空きメモリによって変わります。処理できない場合は素材数や画質を下げてください。
  • 撮影日時順は画像や動画から取得できる撮影情報を優先し、取得できない場合はファイル日時を使います。
